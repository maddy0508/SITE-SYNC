## Existing-model context
At the inspected commit, the migration chain contains the legacy identity/tenancy model (`organisations`, `companies`, `persons`, `user_profiles`, `company_memberships`, `projects`, `project_company_participation`, `project_assignments`, `device_installations`) and the M1.7 attendance model (`sitesync_attendance_day`, `sitesync_sync_command_receipt`, `sitesync_attendance_event`). Semantic overlap is not treated as equivalence.

## Interpretation
**DIVERGENT** means an identifiable existing table is a semantic counterpart but does not satisfy the canonical entity contract. **ABSENT** means no existing public table satisfies the canonical role. AC-04 does not choose migrate/replace/coexist.
